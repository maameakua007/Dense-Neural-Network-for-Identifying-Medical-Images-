# Medical Image Classification

This project uses TensorFlow Dense neural networks to classify six categories of medical images: Abdomen CT, Breast MRI, Chest X-ray, Chest CT, Hand, and Head CT.

The project follows a structured deep learning workflow, including data preprocessing, baseline comparison, model experimentation, validation, and final testing. Different network sizes, depths, and dropout rates were compared before selecting the final model.

The final model achieved approximately 99.8% accuracy on the reserved test set.
